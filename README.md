<p align="center">
PlayerNotes lets you rate, tag, and keep notes on players you meet. Get reminders when tracked players join your party or when friends and players marked Avoid appear nearby.
</p>

## ![Install](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Install&letterSpacing=0.5px&weight=700)

Developed with **Ashita v4.3.2.1**.

1. [Download latest release of PlayerNotes](https://github.com/SQLCommit/PlayerNotes/releases/latest).
2. Extract the ZIP into `/ashita/`. It creates `/ashita/addons/playernotes/`.
3. In game, run `/addon load playernotes`.
4. Use `/pn` to open the window.

The main file should be at `/ashita/addons/playernotes/playernotes.lua`.

**Load automatically:** Add `/addon load playernotes` to your startup script in `/ashita/scripts/`.

## ![Features](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Features&letterSpacing=0.5px&weight=700)

| Feature | What you can see and do |
| :--- | :--- |
| **Player profiles** | Ratings from 0–5, tags, and timestamped notes with zone names. |
| **Pinned notes** | Keep one note at the top of a profile and include it in alerts. |
| **Party and nearby alerts** | Configurable toasts, sounds, colors, and town filtering. |
| **Party review** | Rate and add notes about former party members after disbanding; trusts are excluded. |
| **Search and filtering** | Find players by name or tag, sort the list, or add your current player target. |
| **Import and export** | Share JSON exports between characters while keeping separate local databases. |

**Tags:** Healer, Tank, DPS, Mage, Support, Crafter, Friend, Avoid, and Mentor.

## ![Profiles and alerts](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Profiles+and+alerts&letterSpacing=0.5px&weight=700)

- **Identity:** Profiles can include a character ID. A typed name without an ID is shown as **name only**, with `[unconfirmed]` alerts. Adding a note or rating while that player is with you ties the profile to them.
- **Nearby alerts:** These apply to Friend and Avoid tags. Other tracked players trigger party alerts. Friend-nearby alerts are suppressed in towns by default.
- **Duplicate names:** Importing does not merge different character IDs. Two profiles can share a name; verify the identity before deleting either.

## ![Commands](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Commands&letterSpacing=0.5px&weight=700)

| Command | Action |
| :--- | :--- |
| `/pn` | Show or hide the window |
| `/pn show` / `/pn hide` | Show or hide it explicitly |
| `/pn <name> <note>` | Add a note; create a profile if needed |
| `/pn rate <name> <0-5>` | Set a rating; 0 clears it |
| `/pn tag <name> <tag>` | Toggle a tag |
| `/pn search <term>` | Search by name or tag |
| `/pn export` | Export profiles and notes to JSON |
| `/pn import [file]` | Import a named file, or the latest export if omitted |
| `/pn import list` | List available exports |
| `/pn resetui` | Reset window size, position, and columns |
| `/pn help` | Show command help |

`/playernotes` also works as the command prefix.

## ![Export and saved data](https://readme-typing-svg.demolab.com/?font=Cinzel&size=25&duration=1&pause=0&color=638EBD&center=false&vCenter=true&repeat=false&width=600&height=42&lines=Export+and+saved+data&letterSpacing=0.5px&weight=700)

**JSON exports**

- Exports include notes, ratings, tags, timestamps, and pinned status. Export files are shared across characters.
- Import merges matching identities: the higher rating wins, tags are combined, and duplicate notes are skipped.
- **Files:** `/ashita/config/addons/playernotes/exports/`

**Saved data**

- **Database:** `/ashita/config/addons/playernotes/<CharName>_<ServerId>/playernotes.db`
- **Settings:** `/ashita/config/addons/playernotes/<CharName>_<ID>/settings.lua`
- **Backup:** Copy `/ashita/config/addons/playernotes/` to keep your profiles, settings, and exports.
